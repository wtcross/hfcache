# AD-02 — Begin with the latest observed revision without backfill

- Status: accepted.
- ADR backfill: 2026-10-17; original decision and implementation dates are
  recorded below.
- Authority: the cited architecture contract remains normative. This ADR
  records rationale and history; maintain it under [the ADR policy](../../../../../adr/README.md).

## Context

A newly configured repository may have a long upstream commit history.
The service needs a bounded and well-defined starting point for its rolling
archive.

## Decision

The first successful sync publishes the head of the configured reference
observed by that run. It does not retrieve revisions that preceded the
first observation.

## Rationale and alternatives

The archive records what scheduled runs observe. Reconstructing historical
content would require a different ingestion contract and Git history,
contrary to AD-01 and NG-01.

The recorded decision rules out historical backfill through its rationale.
It does not record a separate comparison of backfill strategies; this ADR
does not invent one.

## Consequences

The oldest archived revision is the first successfully observed SHA.
Operators cannot infer that older upstream commits, or intermediate commits
between observations, exist locally. A failed first sync does not create a
partial published revision.
