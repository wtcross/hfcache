# Approved design reference

These are the actual previously supplied prototype and screenshots, retained unmodified for implementation reference. They use fictional repository identities, sizes, operation handles and deployment data. The HTML performs no real API/authentication and is not a React production implementation; behavior/security details are governed by the plan and living contracts.

Open [the interaction prototype](hfcache-web-ui-mockup.html) locally to inspect navigation and representative workflows. Do not deploy it as the application, copy its mock request behavior into production, or treat prototype buttons/data as proof that an endpoint exists.

- [Library](hfcache-ui-library.png): dense shared model/dataset workspace and filters.
- [Model detail](hfcache-ui-model-detail.png): publication-aware facts, README and variant-oriented structure.
- [Dataset detail](hfcache-ui-dataset-detail.png): dataset-specific declarations without model-only fields.
- [Operations](hfcache-ui-operations.png): persistent interrupted-observation and original-handle recovery.

Implementation screenshots for human guides must be captured from the real built synthetic test deployment and labelled with its actual UI version. Preserve the prototype as design evidence, not as a current user screenshot.
