# AD-21 — Require explicit restricted Hub scope and one consumer authorization boundary

- Status: accepted.
- ADR backfill: 2026-10-17; original decision and implementation dates are
  recorded below.
- Authority: the cited architecture contract remains normative. This ADR
  records rationale and history; maintain it under [the ADR policy](README.md).

## Context

The original scope was public repositories only, although credential
configuration anticipated a later extension. The deployed private network
needs to archive repositories that its service account is authorized to
read, while the exported publication tree has no per-repository ACL layer.

## Decision

Make `hub.token_mode = "required"` the sole opt-in for private and gated
repositories. Resolve an explicit token file or systemd credential before
Hub contact and pass that credential to every Hub call. Keep `disabled`
and `optional` public-only, even if optional mode finds a token. Require
every consumer of the published tree to be authorized for every archived
repository.

## Rationale and alternatives

Explicit scope separates authorization policy from ambient credential
availability. One shared consumer boundary matches the actual export
rather than promising repository isolation that the publication tree does
not enforce.

AD-21 and decision 98 reject automatic restricted scope from an optional
token, per-repository credentials/ACLs for this shared-boundary deployment,
and deletion when a credential or gate loses access.

## Consequences

A missing required credential is `HFARG008` at exit 10. Public-only modes
refuse restricted repositories with `HFHUB006`; an unaccepted gate under
required mode is an access failure (`HFHUB005`). Revocation stops future
fetches without deleting published content. Explicit configuration removal
and purge provide the deletion path. No durable JSON shape changes; the
configuration fingerprint already captures access intent. Rollback to a
pre-HUB-010 binary requires stopping sync and returning configuration to
optional mode without syncing restricted repositories on that release.
