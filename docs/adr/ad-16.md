# AD-16 — Preserve ambiguity and stop instead of guessing

- Status: accepted.
- ADR backfill: 2026-10-17; original decision and implementation dates are
  recorded below.
- Authority: the cited architecture contract remains normative. This ADR
  records rationale and history; maintain it under [the ADR policy](README.md).

## Context

Unknown files or contradictory durable evidence may represent valid
content the current program cannot explain. An automatic heuristic can
turn an inspectable problem into irreversible archive loss.

## Decision

Preserve and report unknown data, unsupported journal versions,
impossible checkpoint combinations, inconsistent manifests, and ambiguous
reference state. Stop the mutating command when recovery cannot prove one
correct resolution. Never use age, mtimes, or another heuristic as deletion
authority on its own.

## Rationale and alternatives

An operator can investigate precise preserved evidence. An incorrect
automatic deletion or rewritten expectation may permanently destroy the
only valid revision.

The original decision rejects guessing among equally defensible
resolutions, silently deleting unknown content, and rewriting evidence to
make state appear coherent. Over-retention is preferred to uncertain
deletion.

## Consequences

Recovery is idempotent and performs only proven actions. Unsupported or
contradictory unresolved state halts mutation at exit 20 before Hub
contact; read-only inspection remains available. Explicit quarantine
cleanup is allowed only after source and recovery journals prove ownership
and retained bytes prove redundancy. Unrelated resolved legacy journals
supply no deletion authority and need not match today's checkpoint order.
