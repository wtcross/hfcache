# AD-01 — Archive complete snapshots at resolved immutable commits

- Status: accepted.

## Context

The archive must preserve a reproducible repository tree even when branches
and tags move or upstream history disappears. A branch name cannot identify
the exact content that an earlier run observed.

## Decision

Archive every file of one model or dataset repository at one full
40-character commit SHA. Resolve the configured reference before download
and pass that SHA explicitly to subsequent Hub metadata and download calls.
The archive preserves snapshots rather than Git history.

## Rationale and alternatives

An immutable commit identifies a stable file set that a manifest can
describe. Re-observing that commit is idempotent and cannot silently select
a different tree.

The original decision explicitly rejects mirroring Git history (`NG-01`):
it increases storage and complexity without helping consumers that copy a
single complete tree. Downloading by a moving branch or tag is rejected by
The original rationale because resolution and download can race.

## Consequences

Completeness compares the downloaded paths and sizes with the upstream tree
at the resolved SHA. A missing or extra file blocks publication. Git history,
other branches, and commits never observed by a run are outside the archive's
completeness promise.
